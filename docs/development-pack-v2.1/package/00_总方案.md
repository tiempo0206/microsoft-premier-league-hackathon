# MatchMind AI 总方案

交付包2.1，接口2.0.0。目标是三个人以少量日常时间完成“合成赛事回放、战术解释、证据核验、个性化展示”闭环，各自可以用不同AI开发。

## 开发与发布原则

开发过程优先中国境内方便获取的资源：内置原创合成数据、清华PyPI镜像、npmmirror、百炼千问API，DeepSeek官方API备用。Microsoft Agent Framework作为实际Agent编排路线，无需先开通Foundry。网页样式、图标和数据随构建打包，不依赖Google字体或远程CDN。

最终网页可以部署到国际站点。B集中处理容器构建与发布，优先验证Render常驻Docker服务；已有Azure订阅也可用普通Container Apps。后端和前端同域，单进程保存回放会话，模型密钥只在后端。云端必须重新验证国内模型API连通性。

## 三人职责

| 角色 | 内容 | 独立开发依据 |
| A | 前端页面、回放控制、证据高亮、双模式、视频 | 本地Mock与冻结TypeScript类型 |
| B | 样例数据、统计、检测、回放API、SSE、部署 | 固定fixture与AI桩函数 |
| C | 模型开户、实际Agent、核验、评测、最终集成 | 固定AnalysisRequest与审核样例 |

C先导入共同基线；之后各角色只改自己的目录。接口、固定样例、共享测试不允许被各自AI随意修改。合并规则和验收命令优先于各AI自己的工程习惯。

## 最小成品

一段明确标为合成的五分钟赛事；比分、射门、传球和持球时间随回放更新；高位夺回窗口触发解释；每条关键解释能展开检查支撑事件；Casual和Analyst模式共用事实；错误引用和数值被拒绝；模型失败仍能回放并标明Rule fallback。

先完成无账号工程闭环，再接真实国内模型，最后接微软框架的实际多Agent协作和小样本对照。快速反击、持续控球、多语言和更多比赛属于P1；录像识别、无球跟踪、训练模型和账号系统不进入首轮。
