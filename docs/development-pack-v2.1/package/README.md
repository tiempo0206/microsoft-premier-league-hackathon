先看 [00_总方案.md](00_总方案.md)，再看 [01_三人开发与AI指令.md](01_三人开发与AI指令.md) 和 [02_国内开发与国际部署.md](02_国内开发与国际部署.md)。完整开发基线在starter-overlay/matchmind。

开发优先国内模型、国内包镜像、本地数据与打包静态资源；最终产品可国际部署。没有注册云账号也能先用Mock和AI桩开发。此包不等于完成的比赛产品。
