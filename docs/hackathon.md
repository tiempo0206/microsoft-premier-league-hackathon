## Submission reminders

- Teams may have up to four members (§3).
- Create a new project using synthetic football data (§§4.3, 4.7).
- Include a pitch, a functioning demo video shorter than two minutes, and a public video link (§4.4).
- **The submitted GitHub repository must be public (§4.4).** This workspace starts private as requested; arrange publication before submission.
- Provide judging access and testing instructions (§4.8).
- Supply submission materials in English or include English translations (§4.9).

This is a working reference. The official sources govern eligibility and submission requirements.
