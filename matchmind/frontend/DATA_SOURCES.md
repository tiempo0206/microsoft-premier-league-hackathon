A real model generating text does not make its input match a real match.

## Requirements before switching the public dataset

Track the cross-role work in [issue #15](https://github.com/tiempo0206/microsoft-premier-league-hackathon/issues/15). C now coordinates the adoption route using the delivered data; B's source acquisition is complete. Calibration can retain contract 2.0.0 and its synthetic replay. An independent real historical replay requires C to version the frozen contract with A/B review and define initial state and provider mapping. A then consumes those agreed fields. No real input may be labelled synthetic to pass the existing validator.

For a historical runtime, A needs reviewed semantics for source kind/provider/version/ID, match date and competition/season, home/away identity, initial clip score, attribution/license and any derivation/missing-data notice. These are review requirements, **not new API field names or an implemented alternate schema**. Until C records the chosen route and any versioned fields, the source disclosure stays a separate reference, outside the playable catalogue. It makes no claim that the current synthetic dataset was calibrated against this match.

The mapping must preserve the original period clocks, outcomes, own-goal handling, coordinates/attack direction and possession semantics. Missing facts remain unavailable. Derived possession estimates and heuristic detections must be labelled as derived; no generated recoveries, player motion or event positions may be inserted into a real match. Verify events against published metadata and reconcile full-match and clip statistics before public acceptance.

The [hackathon rules §4.7](https://github.com/microsoft/insidethegamehackathon/blob/main/OFFICIAL%20RULES.md#47-use-of-footage) require synthetic football-realistic data. A real historical mode therefore also needs an explicit submission-scope decision from the integrator/representative. The current fallback remains plainly synthetic while calibration/adoption, mapping, initial state, contract and submission scope await C's integration decision. Usable research source files have been delivered.
