## Reproduce

Build with `pnpm run build` from `frontend`, then run from `matchmind`:

```sh
MATCHMIND_MODEL_PROVIDER=mock MATCHMIND_SERVE_FRONTEND=1 \
  MATCHMIND_DATA_DIR=data/extra/showcase/press \
  .venv/bin/python -m uvicorn ai.app:app \
  --host 127.0.0.1 --port 18410 --workers 1
```

The browser opened this actual local integrated application, serving the built assets on the same origin. The dense press dataset is an explicitly synthetic local QA selection; it does not change the deployed/default dataset. The model provider was explicitly mock and all observed analysis was labelled Rule fallback / Code only, with a recorded validator trace stating that no model was called.
